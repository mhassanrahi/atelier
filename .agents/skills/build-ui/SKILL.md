Build or update the following UI:

$ARGUMENTS

1. Inspect the current implementation and related components.
2. Search for reusable components before creating new ones.
3. Reuse the existing design systems and patterns.
4. Keep the change focused on the requested feature or page.
5. Verify responsive design and accessibility standards are met.
6. Run and visually verify the application.
7. Run the normal project checks.
8. Fix reproducible issues without expanding the scope of the change.
9. Summarize what was changed.
